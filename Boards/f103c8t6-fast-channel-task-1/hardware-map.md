# STM32F103C8T6 速通任务一硬件与接口规范

## 1. MCU 与时钟

| 项目 | 配置 |
| --- | --- |
| MCU | STM32F103C8T6，LQFP48 |
| 内核 | Cortex-M3 |
| 代码 Flash / SRAM | 62 KB / 20 KB |
| 标定记录 Flash | 2 KB，最后两页 |
| 外部时钟 | 8 MHz HSE |
| SYSCLK | 72 MHz |
| APB1 / APB2 | 36 MHz / 72 MHz |
| HAL/RTOS 时基 | SysTick，1 kHz |
| 调试 | SWD，PA13/PA14 |

Flash 地址分配：

```text
0x08000000..0x0800F7FF  应用代码，62 KB
0x0800F800..0x0800FBFF  校准记录页 0
0x0800FC00..0x0800FFFF  校准记录页 1
```

不得把应用代码或常量放到校准记录区。

## 2. 引脚

| 功能 | 引脚 | 模式 | 说明 |
| --- | --- | --- | --- |
| MPU6050 SCL | PB6 | I2C1 AF 开漏 | 100 kHz |
| MPU6050 SDA | PB7 | I2C1 AF 开漏 | 100 kHz |
| USB-TTL TX | PA9 | USART1 TX，复用推挽 | 115200 8N1 |
| USB-TTL RX | PA10 | USART1 RX，浮空输入 | 115200 8N1 |
| USART1 TX DMA | DMA1 Channel 4 | 内存到外设 | 单次，低优先级 |
| 有源蜂鸣器 | PA0 | GPIO 推挽输出 | 低电平触发，上电高电平 |
| LED | PC13 | GPIO 推挽输出 | 低电平点亮 |
| SWDIO | PA13 | SWD | 保留 |
| SWCLK | PA14 | SWD | 保留 |

USB-TTL 必须使用 3.3 V TTL 电平，不得直接连接 RS-232 电平。

## 3. MPU6050

| 项目 | 配置 |
| --- | --- |
| 7 位地址 | `0x68`，AD0 接地 |
| DLPF | 42 Hz |
| 陀螺量程 | ±500 deg/s |
| 加速度量程 | ±4 g |
| 软件采样率 | 100 Hz |
| I2C 超时 | 10 ms |
| FIFO/DMP | 不使用 |

默认轴映射为单位矩阵，并全部取正。安装方向与车体轴不一致时，必须修改
`App/Src/app_fast_channel.c` 中的 `axis_source` 和 `axis_sign`，并在实板复核六面
方向。

驱动内置零偏标定被设为 0；任务一的陀螺零偏、六面加速度零偏和比例系数由应用层
标定并经 Flash 持久化。

I2C1 初始化前会在 PB6/PB7 上执行 9 个 SCL 恢复脉冲和一次 STOP，用于释放
MCU 复位打断事务时被从设备拉低的 SDA。恢复完成后才把引脚交回 I2C1 复用功能。

## 4. 校准记录

每条记录负载包含：

- 六面进度掩码
- 已完成轴掩码
- 三轴陀螺零偏，单位 rad/s
- 三轴加速度零偏，单位 m/s²
- 三轴加速度比例系数

记录采用双页追加日志，每条槽位 128 字节，头部含 Magic、版本、负载长度、序号和
CRC32。启动时扫描两页并选择序号最新的有效记录。写满当前页后擦除另一页并切换。

## 5. 六面标定

面顺序任意，但六面必须各出现一次。面识别要求：

- 主轴绝对加速度不小于 6.0 m/s²
- 非主轴绝对加速度不大于 5.0 m/s²
- 加速度模长在 7.8..11.8 m/s²
- 标定后的三轴角速度绝对值不大于 3 deg/s

上电初始判断和陀螺零偏采集阶段尚无零偏补偿，因此原始三轴角速度门限为
10 deg/s；陀螺标定完成后立即应用工作零偏，六面流程改用 3 deg/s 门限。

同一新面需要稳定 1 秒，随后采集 100 点。每个新面的搜索/采集窗口为 30 秒。

初始 `-Z` 特殊处理：

- 仅在尚未接受任何面时生效
- `az <= -7.8 m/s²`
- 连续稳定 3 秒
- 满足后跳过六面标定，直接进入主程序

一旦已接受任意面，后续 `-Z` 按正常六面数据处理。

## 6. 蜂鸣器建议电路

模块引脚：

```text
VCC -> 3.3 V
GND -> GND
I/O -> PA0
```

软件在初始化阶段先写高电平关闭输出。若模块上电或复位时短暂误鸣，应在 PA0 与
3.3 V 之间增加 10 kOhm 上拉。不得用 PA0 直接驱动裸蜂鸣器线圈。

## 7. USART1 链路

USART1 使用单一物理回调所有者：

- TX：32 通道 JustFloat，DMA1 Channel 4
- RX：单字节中断，写入 256 字节环形缓冲
- 命令解析和参数提交只在 VofaTask 上下文执行
- TX 不发送 ASCII 应答

JustFloat 使用小端 float 数组和帧尾 `00 00 80 7F`。上位机应持续解析，不要向
TX 插入文本。

## 8. 电气与验证风险

- PC13 驱动能力有限，只能连接板载 LED 或低电流外部指示。
- PA0 为 WKUP 引脚，复位期间模块输入电平需由外部上拉保证。
- MPU6050 模块应有 3.3 V 供电和 I2C 上拉。
- 首次上电先用限流电源，确认 MPU 地址、USART1 回环和蜂鸣器不会持续导通。
- 已实板验证 SWD、Flash 烧录校验、RTT、COM4 50 Hz JustFloat、在线调参、
  陀螺标定、单面写入、跨复位恢复和面超时。
- 仍需人工验证完整六面翻转、初始 `-Z` 跳过、蜂鸣器声音和最终安装轴方向。
