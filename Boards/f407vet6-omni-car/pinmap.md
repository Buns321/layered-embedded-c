# STM32F407VET6 四轮全向小车接线表

本文只用于快速接线。完整外设约束见
[hardware-map.md](hardware-map.md)，板级参数见
`App/Inc/app_car_config.h`。

## 1. 接线前提

- MCU 逻辑电平为 `3.3 V TTL`。
- 电机电源接 TB6612 的 `VM`，不能接 MCU 的 `3.3 V`。
- MCU、TB6612 逻辑电源、编码器、WHT101、蓝牙模块必须共地。
- 所有信号在上电前先断电检查，首次运行应把车轮架空。
- 不要占用 `PA13 / PA14`，它们是 SWD 调试口。

## 2. 轮位定义

从车顶向下看，A、B、C、D 按顺时针排列，安装方向分别为 1:30、4:30、
7:30、10:30：

```text
              车头
       D(10:30)      A(1:30)
       C(7:30)       B(4:30)
              车尾
```

默认机械正方向约定：

- A：1:30，前右。
- B：4:30，后右。
- C：7:30，后左。
- D：10:30，前左。
- 以车头为 0°、向左为正、逆时针增加时，四轮等效角度为
  A=315°、B=225°、C=135°、D=45°。
- 逆时针 yaw / omega 为正。

## 3. TB6612 接线

使用两个双路 TB6612 模块：第一个驱动 A/B，第二个驱动 C/D。

### 3.1 AB 模块

| TB6612 信号 | MCU / 目标 | 说明 |
| --- | --- | --- |
| `VCC` | `3.3 V` | 逻辑电源 |
| `GND` | 公共地 | 必须与 MCU 共地 |
| `VM` | 电机电源正极 | 按电机额定电压 |
| `STBY` | `PC13` | A/B 两路共用 |
| `PWMA` | `PE9 / TIM1_CH1` | A 轮 PWM |
| `AIN1` | `PD0` | A 轮方向 |
| `AIN2` | `PD1` | A 轮方向 |
| `AO1 / AO2` | A 电机两端 | 方向后续标定 |
| `PWMB` | `PE11 / TIM1_CH2` | B 轮 PWM |
| `BIN1` | `PD2` | B 轮方向 |
| `BIN2` | `PD3` | B 轮方向 |
| `BO1 / BO2` | B 电机两端 | 方向后续标定 |

### 3.2 CD 模块

| TB6612 信号 | MCU / 目标 | 说明 |
| --- | --- | --- |
| `VCC` | `3.3 V` | 逻辑电源 |
| `GND` | 公共地 | 必须与 MCU 共地 |
| `VM` | 电机电源正极 | 按电机额定电压 |
| `STBY` | `PE5` | C/D 两路共用 |
| `PWMA` | `PE13 / TIM1_CH3` | C 轮 PWM |
| `AIN1` | `PD4` | C 轮方向 |
| `AIN2` | `PD5` | C 轮方向 |
| `AO1 / AO2` | C 电机两端 | 方向后续标定 |
| `PWMB` | `PE14 / TIM1_CH4` | D 轮 PWM |
| `BIN1` | `PD6` | D 轮方向 |
| `BIN2` | `PD7` | D 轮方向 |
| `BO1 / BO2` | D 电机两端 | 方向后续标定 |

STBY 由固件控制。上电初始为低电平，四轮保持禁用；不要绕过固件长期直接拉高。

## 4. 编码器接线

| 轮位 | 编码器 A 相 | 编码器 B 相 | 定时器 |
| --- | --- | --- | --- |
| A | `PA5 / TIM2_CH1` | `PB3 / TIM2_CH2` | TIM2 |
| B | `PA6 / TIM3_CH1` | `PA7 / TIM3_CH2` | TIM3 |
| C | `PD12 / TIM4_CH1` | `PD13 / TIM4_CH2` | TIM4 |
| D | `PA0 / TIM5_CH1` | `PA1 / TIM5_CH2` | TIM5 |

每个编码器的 `VCC`、`GND` 按模块规格连接，信号必须是 3.3 V TTL。

如果编码器计数方向与轮子机械正方向相反：

- 优先交换该编码器的 A/B 两相接线。
- 或在轮系标定阶段修正对应的 `wheel_sign`。

## 5. WHT101

| WHT101 信号 | MCU 引脚 | 方向 | 说明 |
| --- | --- | --- | --- |
| `TX` | `PA10 / USART1_RX` | WHT101 → MCU | 9600，8N1 |
| `RX` | `PA9 / USART1_TX` | MCU → WHT101 | 9600，8N1 |
| `GND` | 公共地 | 双向 | 必须共地 |
| `VCC` | 按模块规格 | 电源 | 信号必须为 3.3 V TTL |

上电后车体必须保持静止。固件会等待 WHT101 稳定，配置 10 Hz 输出，写入设备侧
yaw 零点，然后执行软件残余零点修正。

## 6. 蓝牙模块

使用一个普通透明传输蓝牙模块，115200，8N1，无硬件流控。

| 蓝牙模块信号 | MCU 引脚 | 方向 | 用途 |
| --- | --- | --- | --- |
| `RXD` | `PA2 / USART2_TX` | MCU → 蓝牙 | JustFloat 波形 |
| `TXD` | `PD9 / USART3_RX` | 蓝牙 → MCU | JoyCon 命令 |
| `GND` | 公共地 | 双向 | 必须共地 |
| `VCC` | 按模块规格 | 电源 | 信号必须为 3.3 V TTL |

注意：

- `PA3 / USART2_RX` 当前不接蓝牙。
- `PD8 / USART3_TX` 当前不接蓝牙。
- 蓝牙模块如果是 5 V 逻辑输出，必须使用电平转换后再接 `PD9`。

JoyCon ASCII 报文：

```text
[j,lx,ly,rx,ry]
```

- 数值范围：`[-100,100]`。
- 换行可选。
- 无校验字段。
- `lx / ly` 使用世界系速度分量。
- `rx` 为世界系自转角速度。
- `ry` 为保留字段。

## 7. SWD

| 信号 | MCU 引脚 | 调试器 |
| --- | --- | --- |
| SWDIO | `PA13` | ST-Link SWDIO |
| SWCLK | `PA14` | ST-Link SWCLK |
| GND | 公共地 | ST-Link GND |
| 3.3 V | 板级 3.3 V | 按调试器要求连接 |

RTT 日志通过 SWD 输出，不占用蓝牙串口。
调试接口必须保持 SWD 模式，不要启用会占用 `PB3` 的完整 JTAG。

## 8. 推荐上电顺序

1. 检查所有模块与 MCU 共地。
2. 先只给 MCU 和 3.3 V 逻辑部分上电，确认无异常电流。
3. 通过 SWD 烧录固件并启动 RTT 日志。
4. 车体静止，确认 WHT101 归零完成。
5. 架空车轮，再给 TB6612 的 `VM` 上电。
6. 发送零输入和低速测试命令，检查四个轮子的方向。
7. 最后落地测试，先限制较低的最大速度和角速度。

## 9. 方向异常检查

| 现象 | 优先检查 |
| --- | --- |
| 单个轮子反转 | 交换该电机 `AO1/AO2` 或 `BO1/BO2` |
| 单轮反馈方向反 | 交换该编码器 A/B 相 |
| 平移时自转 | 检查轮位 A/B/C/D 与 `wheel_theta` |
| 摇杆方向反 | 检查 JoyCon `lx/ly` 坐标约定 |
| 左右转向反 | 检查 `rx` 符号和 WHT101 yaw 安装方向 |
| 四轮都不动 | 检查 STBY、WHT101 归零状态、JoyCon 超时和 RTT 日志 |

不要把 `counts_per_meter`、PID 增益或轮距的占位值当成已经标定完成的实车参数。
