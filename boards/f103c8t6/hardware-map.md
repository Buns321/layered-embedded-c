# STM32F103C8T6 集成板硬件与接口规范

本文是 `boards/f103c8t6/` 的硬件、引脚、CubeMX 资源和板级验证依据。
引脚方向统一按 MCU 侧描述，例如 `PA2 TX` 表示 PA2 是 MCU 的发送端，
应连接 CH343P 的 RXD。

## 1. 板级基线

| 项目 | 配置 |

| MCU | STM32F103C8T6，LQFP48 |

| 逻辑电源 | 3.3 V |
| 外部高速时钟 | 8 MHz HSE，PLL x9 |
| SYSCLK | 72 MHz |
| AHB / APB1 / APB2 | 72 MHz / 36 MHz / 72 MHz |
| APB1 定时器时钟 | 72 MHz |
| 调试接口 | SWD，PA13 SWDIO / PA14 SWCLK |
| HAL 时基 | SysTick |
| RTOS | FreeRTOS，GCC ARM_CM3 端口，CMSIS-RTOS V2 |
| 系统日志 | SEGGER RTT，通过 SWD 输出 |
| CubeMX | 6.18.1，STM32Cube FW_F1 1.8.7 |
| 代码生成 | 每个外设独立的 `.c` / `.h` |

### CubeMX 当前基线

`.ioc` 已生成以下基础配置：

- RCC：8 MHz HSE、PLL x9、72 MHz SYSCLK。
- SYS：SWD 调试和 SysTick 时基。
- GPIO：已生成独立 `gpio.c` / `gpio.h`。
- CRC：已生成独立 `crc.c` / `crc.h`，由 `MX_CRC_Init()` 初始化。
- FreeRTOS：已生成独立 `freertos.c` / `freertos.h`，AUTOSAR 兼容关闭，
  CMSIS-RTOS V2 开启。
- NVIC：使用 4 位抢占优先级，FreeRTOS 可调用 API 的中断优先级阈值为 5。

外设接入时，引脚模式、复用映射、时钟、DMA、NVIC 和全部 `MX_*_Init()`
继续由 CubeMX/Core 生成。Board 和 Platform 只消费已初始化的实例。

## 3. CubeMX、Platform 与 Board 边界

### CubeMX / Core

- 独占 GPIO 时钟、引脚模式、复用映射、外设时钟和 NVIC 配置。
- 独占定时器时基、PWM 模式、编码器模式、输入捕获模式。
- 独占 DMA 通道、数据宽度、循环/单次模式、中断使能和优先级。
- 通过每个外设独立的 `MX_*_Init()` 完成硬件初始化。
- 在生成文件中只修改 `USER CODE` 区域。

### Platform

- 公共头文件只包含不依赖 HAL 类型的枚举、普通数据结构、回调类型和函数声明。
- Platform 消费 CubeMX 生成的 HAL handle，不重复调用 `HAL_*_Init()`。
- PWM、Encoder、USART、GPIO、EXTI 等功能使用各自的实例类型。
- 未启用的实例由 `platform_config.h` 和 CMake 在编译期排除。
- 一个物理外设实例只有一个回调所有者，回调集合在初始化阶段注册。
- IT/DMA 缓冲区在完成回调或错误回调前保持有效，生命周期由调用方保证。
- 中断回调只做状态更新、事件通知和最小数据搬运。
- 粗粒度结果使用 `Platform_StatusTypeDef`，外设细节通过错误快照或错误回调提供。

### Board / App

- Board 负责固定引脚语义、设备所属关系和初始化顺序。
- App 只使用设备接口下发功能命令。
- 每个具体设备拥有独立对象和独立回调上下文。
- 控制任务、传感器任务、显示任务和通信任务之间通过静态对象或 RTOS 原语交换数据。
- 共享 I2C、DMA 和显示缓冲访问时，必须在调用边界明确并发所有权。

## 4. 定时器与 DMA 分配

### 定时器

| 定时器 | 用途 | 引脚 | 关键配置 |
| --- | --- | --- | --- |
| TIM1 | EC11 硬件编码器 | PA8 / PA9 | TI12，四倍频计数，16 位 |
| TIM2 | DRV8833 PWM | PA0 / PA1 | 20 kHz，CH1 / CH2 |
| TIM3 | WS2812 帧生成 | PB4 | 72 MHz，ARR = 89，CH1 partial remap |
| TIM4 | 舵机 PWM | PB8 | 1 MHz 计数，ARR = 19999，50 Hz |
| SysTick | HAL 与 FreeRTOS 时基 | 内核 | 1 kHz tick |

定时器 clock 均为 72 MHz。TIM2 和 TIM4 共用 APB1，但各自拥有独立时基。

### DMA1

| 通道 | 外设请求 | 用途 | 数据 |
| --- | --- | --- | --- |
| Channel 1 | ADC1 | 两通道周期采样 | `uint16_t[2]` |
| Channel 3 | TIM3_UP | WS2812 CCR 帧 | `uint16_t[368]` |
| Channel 6 | USART2_RX | 调试串口接收 | 独立 RX 缓冲 |
| Channel 7 | USART2_TX | 调试串口发送 | 独立 TX 缓冲 |

固定通道复用决定以下实现方式：

- USART2 使用 DMA 收发。
- WS2812 使用 DMA1_Channel3，优先级应高于普通串口传输。
- ADC1 使用 DMA1_Channel1，可配置循环模式。
- I2C1 使用轮询传输，避免占用 USART2 的 DMA1_Channel6/7。
- USART3 使用中断收发，因为其 TX/RX DMA 通道与 TIM3_UP 存在资源冲突。

### NVIC

- FreeRTOS 可调用 API 的中断优先级数值必须不小于 5。
- DMA、USART、EXTI 中断使用固定、集中定义的板级优先级。
- WS2812 完成事件和 ADC 半满事件通过任务通知或信号量传递，不在 ISR 中处理颜色数据。
- 所有共享状态由 ISR 单写、任务单读，或通过 RTOS 原语传递。

## 5. 电源与地

### 电源域

- MCU、AHT20、CH1116、DX-BT24 和数字逻辑使用 3.3 V。
- WS2812、SG90、继电器线圈和 DRV8833 电机电源使用 5 V。
- HC-SR04-P 使用 3.3 V，ECHO 可直接连接 MCU。
- 所有电源域共地。
- 舵机和电机从 5 V 功率轨供电，不经 MCU 引脚或 3.3 V 稳压器。

### 负载预算

| 负载 | 典型值 | 峰值或设计值 |
| --- | --- | --- |
| DX-BT24 | 270 uA | 3.3 V |
| AHT20 | 23 uA | 3.3 V |
| 10 x WS2812 全亮 | 约 150 mA | 按线损和静态电流预留 200 mA |
| SG90 | 90 mA 空载 | 约 750 mA 堵转 |
| 继电器线圈 | 约 71.4 mA | 5 V，0.36 W |
| QMB-09B-03 | 最大约 50 mA | 需要外部驱动级 |
| DRV8833 电机 | 由电机决定 | 每桥持续 1.5 A RMS，模块限流约 1.3 A |

5 V 电源按至少 2 A 连续能力设计，并为舵机和电机堵转、WS2812 瞬态及继电器动作
留出余量。多个大电流负载同时启动时，应限制占空比、错峰启动或提高电源能力。

每颗 WS2812 保留 100 nF 就近去耦，并在灯串入口增加 10 到 100 uF 储能电容。
舵机、继电器和 DRV8833 的电源入口分别就近去耦。

## 6. 串行接口

### USART2: CH343P 调试与命令

| 项目 | 配置 |
| --- | --- |
| MCU TX | PA2，复用推挽 |
| MCU RX | PA3，输入 |
| 对端连接 | PA2 到 CH343P RXD，PA3 到 CH343P TXD |
| 初始帧格式 | 115200 8N1 |
| DMA | RX: DMA1_Channel6；TX: DMA1_Channel7 |

USART2 作为调试、命令和遥测主通道。CH343P 的最终波特率以模块和上位机配置为准，
115200 是首轮验证值。

USART2 拥有独立回调所有者和独立 DMA 缓冲区。命令接收任务和遥测发送模块共享
该串口时，由同一个设备实例管理状态，发送忙时整帧丢弃并累计统计。

### USART3: DX-BT24 BLE

| 项目 | 配置 |
| --- | --- |
| MCU TX | PB10 |
| MCU RX | PB11 |
| 供电 | 3.3 V |
| 默认帧格式 | 9600 8N1 |
| 支持范围 | 2400 到 115200 baud |
| 工作模式 | 默认透明传输 |
| AT 指令结束符 | CR/LF |
| 传输方式 | 中断收发 |

DX-BT24 的典型工作电流为 270 uA，输入电源范围 2.8 到 3.6 V。
WORK-STATUS 和 LINK-STATUS 当前没有连接到 MCU，BLE 连接状态由通信超时和协议心跳判断。

## 7. I2C、传感器与显示

### I2C1 总线

| 项目 | 配置 |
| --- | --- |
| SCL | PB6，复用开漏 |
| SDA | PB7，复用开漏 |
| 模式 | 标准模式，100 kHz |
| 设备 | AHT20、CH1116 OLED |
| 地址格式 | 7 位地址 |
| AHT20 地址 | `0x38`，HAL 左移地址 `0x70` |
| CH1116 地址 | `0x3D`，HAL 左移地址 `0x7A` |

I2C 访问串行化，单次事务带毫秒级超时。总线错误后依次执行 HAL 状态清理、
外设恢复和一次重新探测；连续失败上报给设备状态，不在 ISR 中重试。

### AHT20

- 供电 2.0 到 5.5 V，本板使用 3.3 V。
- 上电后等待至少 40 ms。
- 初始化命令：`0xBE 0x08 0x00`。
- 触发测量：`0xAC 0x33 0x00`。
- 触发后至少等待 75 ms。
- 读取 6 字节数据，首字节为状态，后续为湿度与温度原始值。
- 状态 Bit7 为 Busy，Bit3 为已校准。
- 建议 2 s 采样一次，降低自热影响。

AHT20 和 OLED 共用 I2C1 时，所有访问通过同一总线锁；不得在 AHT20 测量等待窗口内
跨任务并发访问。AHT20 的单设备总线约束见“风险与待确认”。

### CH1116 OLED

- 模块型号 ZJY130-2864KSWLG01。
- 分辨率 128 x 64，单色，1/64 duty。
- 7 位地址 `0x3D` 对应 SA0 接高。
- 逻辑电源范围 1.65 到 3.3 V，本板使用 3.3 V。
- 初始化、显存布局、扫描方向和对比度命令以 CH1116 与模块供应商序列为准。

显示刷新使用完整帧缓冲，I2C 发送在显示任务中执行。共享总线时，每个事务加锁并检查
上一事务状态。

## 8. 模拟采样

### ADC1

| 通道 | 引脚 | 用途 |
| --- | --- | --- |
| IN4 | PA4 | NTC 分压 |
| IN5 | PA5 | 可调电阻 |

ADC1 使用扫描加 DMA1_Channel1，采样结果转换为电压后送入 Filter。
采样时间按源阻抗设置，首轮建议不低于 55.5 cycles；确认分压源阻抗后再调整。

### NTC

- 25 C 阻值 `R0 = 10 kOhm`。
- B 值 `3950`。
- 阻值精度 `±1%`。
- 标称温度范围 `-20` 到 `105 C`。
- 热时间常数不大于 12 s。

B 参数换算公式：

```text
1 / T = 1 / T0 + ln(R_ntc / R0) / B
```

其中 `T` 和 `T0` 使用 Kelvin。分压电阻值、上臂/下臂位置和 ADC 参考电压确认后，
才能把 ADC 原始值换算成 `R_ntc`。

### 可调电阻

PA5 用于验证 ADC、Filter、阈值事件和遥测。输入按 0 到满量程归一化，
具体机械角度与电压关系在标定时记录。

## 9. 数字输入与测距

### 按键与 EC11

| 信号 | 引脚 | 模式 | 语义 |
| --- | --- | --- | --- |
| KEY_1 | PB12 | 输入上拉 | 按下为低 |
| KEY_2 | PB13 | 输入上拉 | 按下为低 |
| EC11 Button | PB15 | 输入上拉 | 按下为低 |
| EC11 Phase A | PA8 | TIM1_CH1 | 编码器 A |
| EC11 Phase B | PA9 | TIM1_CH2 | 编码器 B |

按键和 EC11 按键做 10 到 20 ms 软件消抖。EC11 使用 TIM1 编码器模式，
输入滤波开启，计数方向在首次板上验证时确定并写入标定参数。

### TCRT

PB14 作为 TCRT 数字输出。有效电平、输出类型和阈值电位器状态在板上确认后，
固定到板级输入定义中。若使用 EXTI14，中断只记录边沿时间戳，消抖和状态更新放到任务。

### HC-SR04-P

| 项目 | 配置 |
| --- | --- |
| TRIG | PA11，推挽输出 |
| ECHO | PA10，EXTI10 |
| 供电 | 3.3 V |
| TRIG 脉宽 | 40 到 50 us |
| 测量范围 | 约 2 到 400 cm |

距离公式：

```text
distance_cm = echo_high_us * 0.034 / 2
```

PA10 在上升沿和下降沿中断中读取 DWT 周期计数，任务侧用两个时间戳计算 ECHO
高电平时间。EXTI 只记录边沿和时间戳，超时、距离换算和错误处理在任务中完成。
阻塞测距只用于台架单次验证，不放入高优先级控制任务。

## 10. 执行器与显示外设

### DRV8833

| DRV8833 | MCU | 定时器 |
| --- | --- | --- |
| PIN3 | PA1 | TIM2_CH2 |
| PIN4 | PA0 | TIM2_CH1 |

- VM 输入范围 2.7 到 10.8 V。
- 每桥持续电流 1.5 A RMS，峰值 2 A。
- 模块限流约 1.3 A。
- nSLEEP 通过 33 kOhm 上拉到 VCC。
- nFAULT 未连接 MCU，模块板载 LED 提供故障提示。
- TIM2 PWM 频率使用 20 kHz，PSC = 0，ARR = 3599。

控制真值表按驱动芯片的 IN1 / IN2 语义定义：

| IN1 | IN2 | 输出 |
| --- | --- | --- |
| 0 | 0 | Coast |
| 0 | 1 | 反转 |
| 1 | 0 | 正转 |
| 1 | 1 | Brake |

PIN3/PIN4 与 IN1/IN2 的对应关系确认后，在板级定义中固定 PWM 极性。
首轮 Demo 使用 `PWM + 0` 正转和 `0 + PWM` 反转，采用 fast decay。
方向切换前先把两路输入置 0，再写入新方向。

### SG90 舵机

- 工作电压 4.8 V，使用 5 V 功率轨。
- 空载电流约 90 mA，堵转电流约 750 mA。
- 控制脉宽 500 到 2500 us，中位 1500 us。
- 目标行程约 180 度，死区约 5 us。
- PB8 使用 TIM4_CH3。
- TIM4 计数频率 1 MHz，PSC = 71，ARR = 19999。

初始化后将输出设为中位，再根据应用设置安全限幅。舵机电源与 MCU 电源共地，
信号线只连接 PB8，不从 MCU 引脚给舵机供电。

### 无源蜂鸣器

- 型号 QMB-09B-03。
- 额定 3 V，工作范围 1.5 到 5 V。
- 谐振频率 2700 ± 300 Hz。
- 线圈电阻 16 ± 5 Ohm，最大电流约 50 mA。
- PB9 输出约 2.7 kHz、接近 50% 占空比的方波。

PB9 通过三极管或 MOS 驱动蜂鸣器。TIM4 固定为舵机 50 Hz 时基，
蜂鸣器由独立低优先级任务使用软件定时翻转 GPIO，并支持按持续时间启动和停止。

### WS2812C 灯串

| 项目 | 配置 |
| --- | --- |
| 灯珠数量 | 10，L2 到 L11 |
| 数据输入 | PB4 到第一颗 DI |
| 级联 | 前一颗 DO 到下一颗 DI |
| 串联电阻 | PB4 与第一颗 DI 之间 5.1 kOhm |
| 供电 | 5 V |
| 数据顺序 | GRB，MSB first |
| 单 bit 周期 | 1.25 us |
| 逻辑 0 | 高约 0.40 us，低约 0.85 us |
| 逻辑 1 | 高约 0.85 us，低约 0.40 us |
| RESET 典型值 | 125 us |
| 设计 RESET 窗口 | 160 us |

PB4 使用 TIM3_CH1 partial remap：

- TIM3 计数频率 72 MHz。
- ARR = 89，单 bit 为 90 ticks。
- 逻辑 0 的 CCR = 29，约 0.403 us。
- 逻辑 1 的 CCR = 61，约 0.847 us。
- 10 颗灯需要 240 个 CCR 值。
- 帧尾追加 128 个 CCR = 0，RESET 约 160 us。
- DMA 帧缓冲长度为 368 个 `uint16_t`。
- DMA1_Channel3 从内存半字传输到 `TIM3->CCR1`。

PB4 默认复用为 JTAG NJTRST。CubeMX 或板级 MSP 中先执行
`__HAL_AFIO_REMAP_SWJ_NOJTAG()`，保留 SWD，再配置 PB4 复用开漏输出。
PB4 外部提供 5 V 上拉或电平转换，串联电阻用于信号线匹配，输出速度设为 50 MHz。
TIM3 partial remap 同时提供 CH2/PB5 和 CH3/PB0 的复用路径；WS2812 只启用
CH1，PB5 继电器和 PB0 三色灯红色通道保持 GPIO 输出模式。

驱动约定：

- 帧缓冲和 DMA 状态属于静态 `ws2812_t` 对象。
- `Dev_WS2812_Init()` 绑定 CubeMX 已初始化的 TIM3/DMA，不重复外设初始化。
- `Dev_WS2812_SetColor()` 只修改内存中的 GRB 数据。
- `Dev_WS2812_Show()` 非阻塞启动整帧发送，上一帧未完成时返回 busy。
- DMA 完成回调只更新完成标志或通知任务。
- 修改帧缓冲前必须确认上一帧 DMA 已完成。

若实测颜色通道顺序为 RGB，只在协议编码层交换 R/G 数据，保持上层颜色接口不变。

### 三色灯珠

| 通道 | 引脚 | 默认实现 |
| --- | --- | --- |
| Red | PB0 | GPIO 推挽 |
| Green | PA7 | GPIO 推挽 |
| Blue | PB6 | GPIO 推挽 |

当前映射按 GPIO 开关控制设计。PB6 同时承载 I2C1_SCL，实际功能选择受总线使用状态约束。
共阴/共阳、有效电平和限流电阻确认后，在板级定义中固定亮度语义。

### 单路继电器

| 项目 | 连接 |
| --- | --- |
| MCU 控制 | PB5 |
| 基极限流 | R9 = 3 kOhm |
| 三极管 | SS8050 NPN |
| 继电器 | SRD-05VDC-SL-C |
| 线圈电源 | 5 V |
| 续流二极管 | FR107，反向并联在线圈两端 |
| 输出端 | COM、OPEN/NO、CLOSE/NC |

- PB5 配置为推挽输出，中低速。
- 高电平吸合，COM 连接 OPEN。
- 低电平释放，COM 连接 CLOSE。
- 初始输出锁存为低，初始化完成后再次写入低电平。
- 线圈功率约 0.36 W，电流约 71.4 mA，电阻约 70 Ohm。
- 吸合和释放时间均不大于 10 ms。
- 线圈一端接 5 V，另一端接 SS8050 集电极，发射极接 GND，形成低边开关。
- 继电器没有辅助触点反馈，软件状态表示最近一次命令。

驱动约定：

- `Dev_Relay_GPIO_Init()` 绑定 Platform GPIO，并显式写入关闭状态。
- `Dev_Relay_Base_ON()` 写入吸合电平。
- `Dev_Relay_Base_OFF()` 写入释放电平。
- `Dev_Relay_Base_Toggle()` 翻转软件记录的开关状态。
- 所有继电器操作在任务上下文执行，同一实例只有一个所有者。

## 11. 板级验证顺序

1. SWD、72 MHz 时钟、RTT 日志和 FreeRTOS 心跳。
2. USART2 与 CH343P 的 115200 回环。
3. I2C1 扫描，确认 `0x38` 和 `0x3D`。
4. AHT20 初始化、触发测量和 2 s 周期读取。
5. CH1116 初始化、清屏和局部刷新。
6. ADC1 两通道 DMA 采样，验证 Filter 与遥测。
7. KEY_1、KEY_2、EC11 按键和 TIM1 编码器计数。
8. TCRT 输入电平和阈值。
9. HC-SR04-P 单次测距，再接入周期采样。
10. 继电器无负载吸合、释放和 Toggle。
11. SG90 中位、端点限幅和空载运动。
12. DRV8833 空载正转、反转、Coast 和 Brake。
13. 蜂鸣器音调、启停和持续时间。
14. WS2812 单灯、全灯和 10 灯跑马灯。
15. 三色灯单通道验证，并完成 PB6 功能选择。
16. IWDG 超时和复位。
17. USART3 与 DX-BT24 的 9600 回环和透传。

每个阶段记录供电电流、信号波形和错误计数。WS2812、舵机和电机首次验证时使用限流
电源或独立保险，确认接线后再接入完整负载。

## 12. 风险与待确认

### 电气与安全边界

- 继电器触点侧限用 36 V 及以下低压负载。首次验证只接万用表或低压小负载，
  不得直接接市电或大功率设备。
- 继电器触点侧与 MCU 侧保持足够爬电距离。FR107 方向必须保证线圈断电时正向导通。
- PB5 在复位默认高阻状态，板级应在 PB5 或三极管基极增加 10 kOhm 下拉，
  保证上电和复位期间继电器保持释放。
- SG90 和 DRV8833 的堵转电流可能超过 5 V 电源能力。电源、线径、连接器和保险
  必须覆盖同时工作的峰值电流。

### 资源冲突

| 项目 | 影响 | 处理要求 |
| --- | --- | --- |
| 三色灯 Blue PB6 | 与 I2C1_SCL 直接共用 | 改为空闲 GPIO，或按明确时段切换功能；I2C 使用期间保持 SCL 功能 |
| AHT20 与 OLED 共用 I2C1 | AHT20 手册要求一条总线只连接一个 AHT20，并写明不要连接其他 I2C 器件 | Demo 先按共享总线实测；出现异常时拆分到独立 I2C 外设或硬件总线 |
| 三色灯 PA7/PB0 | 两脚分别对应 TIM3_CH2/CH3 | GPIO 开关可直接使用；PWM 调光不得改变 TIM3 的 WS2812 时基 |
| TIM3 partial remap | CH2/PB5、CH3/PB0 同时具有复用映射 | 只启用 CH1；PB5 与 PB0 保持 GPIO，禁止启用对应比较输出 |
| TIM4 共享 | 舵机需要 50 Hz，蜂鸣器需要约 2.7 kHz | TIM4 保持 50 Hz；蜂鸣器使用软件定时 GPIO |
| TIM3_UP 与 USART3 DMA | DMA1_Channel3 固定复用冲突 | USART3 使用中断收发 |
| USART2 DMA 与 I2C1 DMA | DMA1_Channel6/7 固定复用冲突 | I2C1 使用轮询 |
